# PDAC 임상유전체 확장 분석계획

2026-09-29 사용자 요청에 따라 기존 연구 흐름을 유지하고 추가 예후 가치를 평가한다.
이미 관찰한 결과에 근거하여 확장한 탐색적 분석이며 사전등록 확증 연구로 표현하지 않는다.
기존 산출물은 보존하고 별도 실행 폴더에 새 결과를 만든다.

## 자료와 시간 기준

- 분석 단위는 환자이다. 중복 ID의 4행만 제외한 전체 1,011명을 유지한다.
- KRAS는 임상자료 KRAS_subtype을 사용한다. 출처 비교는 내부 QC로만 남긴다.
- 연구자가 확인한 진단 후 선행치료 전 측정 기준을 임상 검사 및 분자정보에 적용한다.
- 절제연과 수술 병리, 실제 선행치료 및 보조치료 수진 정보는 의미상 수술/치료 과정의 정보다. 이를 진단 시점에서 알 수 있었던 정보로 소급하지 않는다.
- OS 시작점은 Dictionary에 정의된 수술 시점을 유지한다. 진단일부터의 OS로 변경하지 않는다.
- 결과는 수술 환자 코호트의 수술 후 예후 연관성/내부 검증으로 해석한다. 전체 진단 PDAC나 치료 효과로 일반화하지 않는다.

## 고정된 분석

1. 기존 24개 유전자–병리 CMH와 BH, 모든 쌍별 Holm 결과를 유지한다.
2. Cox의 연령을 자연 스플라인 3 df로 수정한다. 기본 모형과 병리 확장 모형을 모두 보존하고 본문에는 분화도를 포함한 병리 확장 모형을 우선 제시한다. 초기 확장 모형에서 분화도의 PH 위반을 확인하여 분화도별 기저위험을 허용하는 stratified Cox로 보완하였다. 해당 진단 후 수정 사실을 명시한다.
3. TP53–저분화(PD vs WD/MD)와 CDKN2A–림프절 양성(N1/2 vs N0)의 조정 OR, 표준화 확률, 차이를 추가한다. 연령, 성별, T, M, 선행치료를 보정한다. 원래 범주 전체 검정은 유지한다. 두 확장 연관성의 p는 Holm 보정한다.
4. 같은 complete-case 환자에서 임상병리 모형, +KRAS 아형, +driver count, +KRAS 아형/TP53/SMAD4/CDKN2A를 비교한다. 노출 변수 p로 모형을 선택하지 않는다.
5. 36개월 사망위험 점수와 36개월 행정 검열을 사용한 Harrell C-index, 12/24/36개월 IPCW Brier score와 보정도, 분화도 층화 calibration slope를 평가한다. 500회 환자 bootstrap으로 낙관성을 보정한다. 별도의 out-of-bag paired bootstrap 분포의 중앙 95% 범위는 검증 변동성 구간이며, 낙관성 보정치 또는 보정 차이의 신뢰구간으로 오기하지 않는다.
6. 아형별 공통 공변량 표준화 생존확률과 모든 쌍별 절대 차이를 12/24/36개월에 보고한다. 점별 bootstrap CI는 동시 CI가 아니다.
7. 선행치료와 KRAS 아형의 전체 상호작용을 탐색하고 하위집단별 결과 및 M0 민감도 분석을 제시한다. M1을 전체 OS에서 제외하지 않는다.
8. CA19-9(log1p), ASA를 추가한 민감도 모형을 평가한다. 보조항암치료 yes/no를 수술 시점 고정 노출로 넣지 않는다.
9. 비례위험 위반이 우려되는 재발 및 TMB는 시간가변 효과 분석을 추가한다. 기록된 재발은 사망 포함 DFS 또는 경쟁위험 누적발생률로 재정의하지 않는다.
10. TMB 결측 분포를 기술한다. 수치 대체, 임의 TMB-high 임계값, 기능적 HRD/dMMR 추론은 하지 않는다.

## 해석 및 검증

모든 HR/OR에 비교군, 기준군, 사건 정의를 기록한다. HR>1은 비교군의 사건 hazard가 더 크다는 뜻이며 누적 사망확률 또는 암 발병확률의 증가율과 다르다. 통계적 불확실성과 보정 p를 함께 설명한다.
내부 검증 성능과 외부 임상 유용성을 구분한다. 긍정적 결과에 맞춰 cutoff나 하위집단을 선택하지 않는다. 사전 정의된 모든 모형과 검정을 보존하며 실패한 반복/추정도 수와 이유를 보고한다.
